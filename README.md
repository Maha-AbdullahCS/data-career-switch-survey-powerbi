# Data Career Switch Survey — Power BI Dashboard
## About the Project

An interactive Power BI dashboard analyzing survey data from professionals who transitioned into different data-related career fields. The project explores career backgrounds, salaries, job roles, programming languages, and other factors related to careers in data.

## Tools
- Power BI
- Power Query

## Data Source

The dataset was originally provided by Alex The Analyst for educational purposes and is available through his GitHub repository.

[Original Dataset & Resources](https://github.com/AlexTheAnalyst/Power-BI/tree/main)

## Data Preparation

The dataset was cleaned and prepared using Power Query before being used to build the Power BI dashboard.

Key preparation steps included:
- Removing unnecessary columns
- Handling missing and null values
- Correcting data types
- Cleaning and standardizing text values
- Preparing the data for analysis and visualization

## Dashboard

The Power BI dashboard provides an interactive overview of the survey data, allowing users to explore different aspects of careers in data-related fields through interactive visualizations and filters.

The Power BI dashboard file is included in this repository:

`Data_Career_Switch_Survey_PowerBI.pbix`

## Project Files

- `Data_Career_Switch_Survey_Raw.xlsx` — Original raw dataset before cleaning.
- `Data_Career_Switch_Survey_Cleaned.csv` — Cleaned dataset after data preparation.
- `Data_Career_Switch_Survey_PowerBI.pbix` — Power BI dashboard project file.
- `dashboard.png` — Preview of the final dashboard.
